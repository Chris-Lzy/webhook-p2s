    📡 扫描局域网拓竹打印机

    点击「开始扫描」自动发现局域网内的拓竹设备（SSDP 组播 + 端口探测）。

    耗材库

    单价：元 / 千克（CNY/kg）
    官方 RFID 料盘在 AMS 上报新的 tag_uid + tray_uuid 时自动建档，只需补单价。没有芯片的第三方料盘在这里手工录入，并绑定到打印机槽位（含外挂 vt_tray）。
    唯一身份是 tag_uid + tray_uuid。余量 -1 表示打印机不知道还剩多少，页面显示「未知」，不会当成 0 克。

    装填记录

    打印机不提供装填时间。这里只在本服务在线时推断：槽位从空变为有料，或 tag_uid / tray_uuid 发生变化。服务离线期间换料，无法还原真实时间，重新上线后的第一次看见只当作基线，不会补记一条装填。

    打印任务

    优先从打印机 FTPS（用户 bblp，端口 990）读取 3mf / gcode 里的 used_g、used_m 和盘预览。部分固件登录成功但目录是空的（只有 . 和 ..，/data 返回 550），这时改用余量百分比估算。两种都没有就标成未知，不会写成 0。
    用量来源：文件 = 切片元数据；估算 = 标称重量 × 余量差 / 100；未知 = 余量为 -1 或缺少重量。缺单价的成本显示「待补全」，补上单价后会重算，不会当成 0 元。

    报表

    同一模型多次打印会汇总次数、总克数、总成本，以及已算清任务的平均 / 最低 / 最高成本。缺单价或未知用量的任务不计入总成本。
