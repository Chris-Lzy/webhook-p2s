# webhook-p2s — 拓竹打印机监控通知服务

轻量级拓竹（Bambu Lab）打印机局域网监控服务：通过打印机本地 MQTT 接口实时获取打印状态，将开始 / 完成 / 失败 / 暂停 / 恢复 / 进度等事件推送到**钉钉群机器人**、**企业微信机器人**及**飞书机器人**。自带 Web 控制台与局域网自动扫描，Docker 一键部署，无需注册第三方云服务、数据不出局域网（外部推送除外）。

## 功能特性

- **超大多设备管理（支持最高 1000 台）**：从原先固定 20 台扩展为动态设备管理，最高支持 1000 台打印机席位；支持任意**动态添加**、**删除**设备；提供实时名称 / IP / 序列号 / 状态的即时模糊搜索过滤。
- **📡 局域网设备扫描发现**：内置双模扫描引擎（拓竹专用 SSDP 组播/广播发现 + 局域网 8883 端口快速并发探测），一键自动检索局域网在线的拓竹设备，支持型号识别与**一键添加**至列表。
- **多渠道协同推送**：
  - **钉钉群机器人**：支持 Webhook 地址、HMAC-SHA256 加签密钥及自定义关键词；
  - **企业微信机器人**：支持群机器人 Webhook，Markdown 富文本消息格式；
  - **飞书群机器人**：支持群机器人 Webhook，支持加签密钥防伪。
  - 各渠道具备独立开关与独立测试按钮，可同时多端推送。
- **Web 控制台**：打印机名称 / IP / 序列号 / 访问码全部在页面上填写；密钥类配置脱敏显示、留空保持不变。
- **实时状态遥测**：每台设备独立显示连接状态、打印进度条、当前层数/总层数、剩余时间、喷嘴 / 热床温度、任务文件名、已用时间。
- **摄像头画面抓取**：推送时自动抓取对应打印机的 RTSP 画面流，快照图直接内嵌在消息中，并附带短视频链接（2–15 秒可调）。
- **事件推送（可按需勾选）**：开始打印 / 打印完成 / 打印失败 / 暂停 / 恢复 / 打印中离线 / 进度节点（每 N% 推一次）。
- **推送时间段与免打扰**：可添加最多 8 个时间段，支持跨午夜（如 22:00–07:00）和按星期筛选；每个时段单独勾选要推送的事件。未添加任何时段时全天推送。
- **连通性测试**：每台设备提供独立的「测试」按钮校验 MQTT 连接与摄像头抓图预览；各推送渠道支持一键测试。
- **事件日志**：记录最近 100 条推送与连接事件；被时间段拦截的推送记录为「已跳过」。
- **Docker Compose 一键部署**：配置持久化到 `./data`，默认时区 `Asia/Shanghai`。

## 快速开始

```bash
git clone https://github.com/Chris-Lzy/webhook-p2s.git
cd webhook-p2s
docker compose up -d --build
```

浏览器打开 `http://NAS的IP:8787`，按页面提示配置即可。

## 配置与使用指南

### 1. 打印机设置与局域网发现

1. 打印机屏幕：**设置 → 局域网 / LAN 模式**，开启后页面会显示**访问码（Access Code）**。
2. 打印机与服务部署宿主机（如 NAS、服务器）处于同一局域网。
3. **自动扫描添加**：点击页面上的「📡 扫描局域网」，服务将自动检索当前网段的拓竹打印机并识别型号（X1 / P1 / A1 等），点击「➕ 添加到列表」后仅需填入访问码即可保存启动。
4. **手动添加**：随时点击「➕ 添加设备」输入 IP、SN、访问码，点「保存全部」后点「启动」。

### 2. 推送渠道设置

在右侧「推送渠道配置」中支持配置与测试各渠道：

| 渠道 | 配置项 | 说明 |
|---|---|---|
| **钉钉群机器人** | Webhook、加签密钥 (SEC...)、自定义关键词 | 消息格式为 Markdown，支持图文与短视频链接 |
| **企业微信** | Webhook | 支持企业微信群机器人 Markdown 推送 |
| **飞书机器人** | Webhook、加签 Secret | 支持飞书群机器人消息推送与签名防伪 |

> 提示：各渠道独立控制开关，配置留空时保存不会覆盖已保存的密钥。

### 3. 通知规则与时间段

| 开关 | 默认 | 说明 |
|---|---|---|
| 通知总开关 | 开 | 关闭后仅记录事件、不推送 |
| 开始打印 | 开 | 空闲 / 完成 / 失败 → 打印中 |
| 打印完成 | 开 | 含耗时统计 |
| 打印失败 | 开 | 含错误码 |
| 暂停 / 恢复 | 关 | 设备暂停及继续打印事件 |
| 打印中离线 | 开 | MQTT 断连且正在打印时提醒 |
| 进度节点推送 | 开 | 每推进 25% 推一次（可改 5–100） |

**推送时间段规则**：
- 支持添加最多 8 个独立时段，多时段取**并集**（命中任意一个且勾选了对应事件即推送）；
- 支持跨午夜（如 `22:00–07:00`）；
- 支持按星期单独勾选（周一至周日）。

## 架构与工作原理

- 为每台已启用的设备维护独立的 `PrinterMonitor` MQTT over TLS 客户端（端口 8883，用户名 `bblp`，访问码为密码），监听 `device/<SN>/report`。
- 局域网扫描器通过 UDP 2021 端口向 `239.255.255.250` 发送 SSDP `M-SEARCH` 广播，同时多线程探测网段 8883 端口。
- 摄像头抓流采用系统 `ffmpeg` 访问 `rtsp://bblp:<access_code>@<host>:322/stream` 抓取画面。
